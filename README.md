# Kickstart Hell

Ein Prank-Plattformer für den **Amiga 500**. Fünfzig Räume, und jeder einzelne
bricht sein Versprechen: Der Boden fällt weg, sobald man ihm traut. Die Stacheln
fahren genau dann aus, wenn man springt. Die Tür läuft davon, kaum kommt man ihr
nahe.

Der eigene Dreh: Das Spiel trollt nicht nur mit Fallen im Raum, sondern mit dem
Amiga selbst. Falsche Guru Meditations, falsche Requester, ein Bildschirm, der
wegrutscht, ein Ladebalken, der nie fertig wird.

Inspiriert von *Level Devil* (Unept, 2023).

## Starten

`KickstartHell.adf` auf eine Diskette schreiben oder in einen Emulator einlegen —
die Diskette bootet sich selbst, es muss nichts installiert werden.

Benötigt wird ein **Amiga 500 mit Kickstart 1.3**. Auf einem unerweiterten
Gerät mit 512 KB läuft das Spiel, aber ohne Musik: dafür reicht der Speicher
nicht. Ab einer Speichererweiterung mit 512KB spielt auch die Musik.

## Steuerung

| Taste | |
|---|---|
| Joystick (Port 2) | laufen, Feuerknopf springt |
| Pfeiltasten links/rechts | laufen |
| Leertaste | springen |
| Esc | beenden |

Auf dem Titelbild startet Feuer oder die Leertaste das Spiel.

Wer durch alle fünfzig Räume kommt, darf sich mit seiner Anzahl Tode in die
Bestenliste eintragen. Die Highscoreliste wird automatisch abgespeichert.

Wer schafft es, ohne zu sterben?

# Kickstart Hell

A prank platformer for the **Amiga 500**. Fifty rooms, and every one of them
breaks its promise: the floor drops away the moment you trust it. The spikes
come out exactly when you jump. The door runs off as soon as you get near it.

The twist: the game doesn't only troll you with traps in the room, but with the
Amiga itself. Fake Guru Meditations, fake requesters, a screen that slides
away, a loading bar that never finishes.

Inspired by *Level Devil* (Unept, 2023).

## Running it

Write `KickstartHell.adf` to a floppy or put it into an emulator — the disk
boots on its own, nothing has to be installed.

You need an **Amiga 500 with Kickstart 1.3**. On an unexpanded machine with
512 KB the game runs, but without music: there isn't enough memory for it. With
a 512 KB memory expansion the music plays as well.

## Controls

| Key | |
|---|---|
| Joystick (port 2) | walk, fire button jumps |
| Cursor keys left/right | walk |
| Space | jump |
| Esc | quit |

On the title screen, fire or the space bar starts the game.

Anyone who gets through all fifty rooms may enter the highscore list with
their number of deaths. The highscore list is saved automatically.

Who can do it without dying?
