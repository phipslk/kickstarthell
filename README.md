# Kickstart Hell

Ein Troll-Plattformer für den **Amiga 500**. Fünfzig Räume, und jeder einzelne
bricht sein Versprechen: Der Boden fällt weg, sobald man ihm traut. Die Stacheln
fahren genau dann aus, wenn man springt. Die Tür läuft davon, kaum kommt man ihr
nahe.

Der eigene Dreh: Das Spiel trollt nicht nur mit Fallen im Raum, sondern mit dem
Amiga selbst. Falsche Guru Meditations, falsche Requester, ein Bildschirm, der
wegrutscht, ein Ladebalken, der nie fertig wird.

Inspiriert von *Level Devil* (Unept, 2023).

## Starten

`KickstartHell.adf` auf eine Diskette schreiben oder in einen Emulator einlegen —
die Diskette bootet sich selbst, es muss nichts installiert werden.

Benötigt wird ein **Amiga 500 mit Kickstart 1.3**. Auf einem unerweiterten
Gerät mit 512 KB läuft das Spiel, aber ohne Musik: dafür reicht der Speicher
nicht. Ab einer Speichererweiterung mit 512KB spielt auch die Musik.

## Steuerung

| Taste | |
|---|---|
| Joystick (Port 2) | laufen, Feuerknopf springt |
| Pfeiltasten links/rechts | laufen |
| Leertaste | springen |
| P | Pause |
| Esc | beenden |

Auf dem Titelbild startet Feuer oder die Leertaste das Spiel.

Wer durch alle fünfzig Räume kommt, darf sich mit seiner Anzahl Tode in die
Bestenliste eintragen. Die Highscoreliste wird automatisch abgespeichert.

Wer schafft es, ohne zu sterben?
